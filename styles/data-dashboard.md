# 数据仪表盘风

适用场景：经营指标、数据趋势、状态概览与分析报告。

来源：codex-ppt 内置风格 `数据仪表盘风.md`，移植并适配为文档配图；本文件可独立使用，不依赖源技能。

### 提示词

明亮的现代 SaaS / BI 数据界面视觉。白色或极浅底、白卡片、细边框与柔和浅影；主色数据蓝 #2563EB 或 #1976D2，辅以青 #06B6D4、柔紫 #8B5CF6。
标题为清晰粗无衬线；关键数值用大号等宽数字，图表标签虽小但必须可读。文字深蓝灰 #0F172A 和中性灰 #64748B。绿 #10B981、橙 #F59E0B、红 #EF4444 仅表达真实状态。
按数据关系选择指标卡、折线、柱状、进度环、迷你趋势线或对比结构，不强制固定指标数量。数值、比例、坐标与单位必须来自任务材料，不以随机数填充界面；无数值时改用定性关系图。
避免深色监控大屏、赛博光效、压迫性黑面板、微小密集表格与无逻辑数据装饰。

生成一张文档配图。画幅比例遵循本次调用参数，封面或正文用途遵循本次任务；不套用固定幻灯片尺寸、页数、导航或页码。
只使用本次任务提供的标题、正文、数据及素材；不渲染提示词中的结构说明、示例词或占位符，不编造指标、来源和年份。中文、术语、数值及单位必须准确清晰，元素不重叠，文字不截断，无水印和无关 logo。
系列配图保持配色、字体与图形语言一致，构图依内容变化。竖幅时重排阅读顺序，不拉伸或裁切横幅布局。
